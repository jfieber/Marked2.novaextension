# Marked for Nova

This extensions adds a _View in Marked_ command to the _Editor_ menu to open the current [Nova](https://nova.app) document with the [Marked 2](https://marked2app.com) or [Marked 3](https://markedapp.com) Markdown previewer.

This extension is not written or endorsed by [Brett Terpstra](https://brettterpstra.com), the creator of [Marked](https://markedapp.com).

## Extension Preferences

You can set the path to the Marked application in the Extension Preferences. Leaving this unset will use the newest installed version, but if you have multiple versions of Marked installed and wish to use a specific one, you can override the default.
